# 2026-10-03 独立远程界面（0.2.0）

## 做了什么

- 连接方式：选择模式只保存偏好，点"切换到…"才真正切换；远程设备发起切换时先收到确认再断开。
- 远程入口换成自己的界面，本机桌面和 `dsh web` 的官方界面不变。
- 界面形态参照 Claude / ChatGPT 手机客户端：圆形悬浮按钮的顶栏、带图标导航和纯文本会话列表的抽屉、胶囊形输入框（＋、会话选项、模型、发送）。配色沿用 `docs/ui-spec.md` 的暖色与陶土橙。
- 根目录 `DSH-PLUGIN-UI-SPEC.md` 为各插件共享的 UI 规格，本仓库保留副本。

## 接手后修掉的问题

宿主端：

- 局域网 IP 变化后网关拒绝新地址：改为每次请求按当前网卡地址判断。
- 二维码可能指向虚拟网卡或 TUN 地址：按网卡名和地址段排序，物理局域网地址优先。
- 设备数到 32 台后无法再配对（公网模式每次换域名都会新增设备）：淘汰最久未使用且不在线的设备。
- 宿主接口的普通 403 被当成"授权已失效"：只认网关自己的 `unpaired`。
- 公网自检连续失败就拆连接：启动验证放宽到 60 秒；连接建立后的失败只提示。
- 远程入口脚本缓存一小时，升级后可能白屏：入口与样式改为每次校验，带哈希的分片长期缓存。
- 网关转发的请求带内部标记，本机管理接口见到标记即拒绝（原来只靠路径拦截）。
- 偏好文件损坏导致插件无法加载：回退默认值并提示。

远程界面：

- 加了根级和分区错误边界，渲染异常不再整页空白。
- "其他宿主功能"不再重复列出已归类的配置。
- 键盘鼠标设备 Enter 发送、Shift+Enter 换行；触屏保持 Enter 换行；输入框随内容增高。
- 深色主题下代码块跟随主题。
- 远程停用或卸载本插件前给出确认。
- 对 rc.2 内部结构的读取集中到 `src/remote/host.ts`，带存在性检查。

工程：`lib/` 不再提交到 git，发布流程会先构建。
